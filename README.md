# GTA Clip Tools 🎮

Tools and scripts that speed up the workflow for my GTA VI clipping channel:
trimming clips, converting them to vertical Shorts, and preparing uploads.

> Unofficial fan project. Grand Theft Auto VI is owned by Rockstar Games
> and Take-Two Interactive. This project is not affiliated with or endorsed by them.

## Features
- [ ] Trim clips by start and end time
- [ ] Convert 16:9 clips to 9:16 for Shorts
- [ ] Batch rename and organise clips
- [ ] Generate titles, descriptions and hashtags

## Tech Stack
Python, FFmpeg

## Getting Started
1. Clone the repo
   git clone https://github.com/Deevan1024/gta-clip-tools.git
2. Install FFmpeg from ffmpeg.org
3. Run a script
   python trim.py
